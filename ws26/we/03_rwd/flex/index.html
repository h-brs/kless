Flexbox verstehen.

Ändere die drei Werte für jedes Element. Der Browser verteilt den Platz – du siehst sofort, wie breit die Elemente tatsächlich werden.

Starte mit gleichen Werten. Jedes Element erhält denselben Anteil am zusätzlichen Platz.

03 Ergebnis verstehen

Zusätzlichen Platz verteilen

Die grow-Faktoren bestimmen, welchen Anteil des zusätzlichen Platzes jedes Element erhält.

Die Ergebniswerte sind im Browser gemessen und auf eine Nachkommastelle gerundet. Bei sehr schmalen Boxen kann die Beschriftung abgeschnitten sein; hier bleiben alle Werte lesbar.

Was bedeuten die drei Werte?
flex-grow · zusätzlicher Platz
Gewicht für das Wachsen. Bei 0 erhält das Element keinen Zuwachs. Ein doppelt so großer Faktor bedeutet nicht automatisch eine doppelt so große Endbreite.
flex-shrink · fehlender Platz
Gewicht für das Schrumpfen. Dabei zählt auch die Basisbreite: shrink × basis. Bei 0 schrumpft das Element nicht.
flex-basis · Ausgangsgröße
In diesem Versuch ist das eine Breite in Pixeln. Nach dem Wachsen oder Schrumpfen kann die tatsächliche Breite anders sein. CSS unterstützt auch weitere Basiswerte, etwa auto und Prozentangaben.

Hier gelten eine Zeile (nowrap), gap: 0 und min-width: 0. Die Flex-Items haben keine Rahmen, Margins oder Paddings. So beeinflussen diese Größen die Rechnung nicht. Die Textabstände liegen in einem inneren Element.

Ohne min-width: 0 kann die automatische Mindestbreite eines Flex-Items das Schrumpfen begrenzen.
